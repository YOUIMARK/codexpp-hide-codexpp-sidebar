# 隐藏 Codex++ 侧栏按钮

隐藏 Codex++ 在 Codex 左侧导航栏添加的入口，不影响 Codex 原生按钮。

## 安装

在 Codex++ 管理器打开「拓展 → 社区拓展」，搜索 `hide-codexpp-sidebar` 点安装；
或从 [Releases](https://github.com/YOUIMARK/codexpp-hide-codexpp-sidebar/releases) 下载 `hide-codexpp-sidebar-v<版本>.zip`，解压到 Codex++ 的拓展目录。

## 需要的能力

| 能力 | 内容 |
| --- | --- |
| 页面脚本 | `main.js` |
